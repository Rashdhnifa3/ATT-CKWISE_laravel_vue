# الأدلة

كل البيانات عامة (ATT&CK Enterprise 20.1 الرسمية) أو اصطناعية. المسارات المحلية مستبدلة: `<worktree>` و`<original>` و`<evidence>` و`~`.

| المجلد | المحتوى |
|---|---|
| `baseline/` | حالة الأصل قبل العمل: HEAD، والحالة، وبصمات sha256 للملفات. وفيه سجلات `npm ci` والبناء وKarma وPlaywright للأصل |
| `final/` | التشغيل النهائي بعد آخر تعديل على كود التطبيق: `summary.txt` و`run-final.sh` وسجل لكل خطوة. ملفات `additions-*` هي الاختبارات المضافة بعده، مع إثبات أن كود التطبيق لم يتغير. `attempt1-port-clash-summary.txt` محاولة أولى أُلغيت بسبب تعارض منفذ سببه هذا العمل نفسه |
| `clean-checkout/` | استنساخ نظيف للفرع، ثم `composer install` و`npm ci` والاختبارات واختبارات المتصفح |
| `compat/` | تقارير المقارنة Angular ↔ Vue (JSON)، وصادرات الملفات من التطبيقين، ولقطات مختارة مع صور الفرق |
| `diffs/` | الفروق المكتشفة: نتيجة Angular ونتيجة Vue، مسجّلتان قبل الإصلاح |
| `concurrent-changes.txt` | تغييرات حدثت في الأصل والـ worktree أثناء العمل وليست من هذا العمل |
